# OT Anomaly & Alarm Monitor

A learning project exploring how operational monitoring data supports OT/ICS security incident investigation.

**Author:** Sreeram Manath  
**Background:** B.Tech Mechanical Engineering | ~2 years Oil & Gas Maintenance  
**Purpose:** Personal portfolio project for OT/ICS security internship applications  

## Overview

This project simulates OT sensor data (current, temperature, vibration) and implements:

- Threshold-based alarms for each signal  
- Statistical anomaly detection to identify baseline shifts  
- Automated shift report with security-relevant observations  

The goal is to explore how operational monitoring data can support OT security monitoring and incident investigation in industrial environments.

## Files

- `ot_anomaly_alarm_monitor.ipynb` – Full notebook with code and visualizations  
- `plot1_sensor_signals_with_thresholds.png` – Sensor signals with alarm thresholds  
- `plot2_baseline_shift_anomaly_detection.png` – Baseline shift / anomaly detection  
- `shift_report_screenshot.png` – Sample shift report output  
- `OT_Anomaly_Alarm_Monitor_Presentation.pdf` – 5-slide overview presentation  

## Note

All data is fully simulated. No real assets, company data, or internal configurations are used.
